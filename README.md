# Drift Donors — бесплатная таблица доноров для ссылок Sape, GoGetLinks и Miralinks

**Drift Donors** — бесплатная база ссылочных доноров с бирж Sape, GoGetLinks и Miralinks от [SEO Drift](https://seo-drift.ru/). Автор — линкбилдер Роман Михальчук. По каждой площадке в одной строке собраны цены на всех трёх биржах, SEO-метрики, видимость в Яндексе и Google, флаги риска и итоговая оценка Drift Score (0–100) с грейдом A–F.

Выпуск выходит примерно раз в месяц, в формате Excel (.xlsx).

## Light или Full

**Light** нужен для быстрого отбора доноров. В нём есть:
- цены на трёх биржах, «Где дешевле» и экономия в ₽ и %;
- ИКС, DR, TF/CF, трафик, возраст домена;
- видимость в Яндексе и Google (keys.so);
- флаги риска: недоступен из РФ, noindex, накрутка трафика или DR, истекающий домен;
- **Drift Score** (итоговая оценка донора 0–100), грейд A–F, а также Authority, Spam Risk, Clean Score, Value Score;
- готовые подборки: «ТОП-100 качества», «дёшево и сердито», «новинка».

**Full** нужен для глубокого разбора. К Light добавляются:
- трафик по источникам: SimilarWeb, Semrush, Ahrefs, LiveInternet и разброс между ними;
- полная видимость keys.so: ТОП-1/3/5/10/50, страниц в индексе, результативность;
- техника: IP, NS, SSL, CMS, антибот, ID Метрики и GA, маркировка erid;
- WHOIS: даты регистрации и окончания, регистратор, признаки дропа;
- данные бирж: индексация статей, проекты Sape, траст GGL, скрытый URL Miralinks.

В обоих файлах есть лист **«Легенда»** с описанием каждой колонки и цветовой подсветки.

## Грейды

| Грейд | Что значит |
|---|---|
| A | отличный донор, можно брать |
| B | хороший |
| C | средний, стоит проверить руками |
| D | слабый |
| F | красный флаг: недоступен, истёк или заблокирован РКН |

Грейд выставляется по **Drift Score** — итоговой оценке донора от 0 до 100. Она объединяет авторитетность, чистоту, индексацию статей и качество реальных размещений. Как считается Drift Score: https://seo-drift.ru/drift-donors/drift-score/

## Другие способы работы с базой

- **Расширение Drift Donors для Chrome.** Показывает те же данные прямо в каталогах Sape, GoGetLinks и Miralinks: цены других бирж, оценку, вердикт «брать / не брать». Подробнее: https://seo-drift.ru/drift-donors/extension/
- **MCP для ИИ-агентов.** Позволяет подбирать доноров через Claude, ChatGPT и других агентов: https://seo-drift.ru/drift-donors/mcp/

## Важно

- Цены и метрики зафиксированы на дату выпуска. Перед покупкой проверяйте площадку на бирже.
- Drift Donors — независимый проект, он не связан с Sape, GoGetLinks и Miralinks.
- Данные собраны из открытых источников и данных бирж. Грейд — это подсказка, а не гарантия.
